| Concept                                                                                                         | What it means                                                                                                                                                                                                                                                                                                                                                                            |
| :-------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[001 Introduction to AI#What is AI?\|AI]]                                                                      | The simulation of human intelligence processes (learning, reasoning, pattern recognition, decision-making) using machines powered by mathematics, statistics, and probability.                                                                                                                                                                                                           |
| [[001 Introduction to AI#Intelligence as decision-making\|Decision-Making]]                                     | The fundamental function of intelligence that receives environmental information as input and transforms it into an action or output decision.                                                                                                                                                                                                                                           |
| [[001 Introduction to AI#Functions: The basic idea behind AI\|Function]]                                        | A mathematical or computational transformation process $f(x) = y$ that takes input information ($x$) and produces an output decision ($y$).                                                                                                                                                                                                                                              |
| [[002 Intoduction to ML#^30873c\|Machine Learning]]                                                             | A subfield of AI focused on algorithms that automatically learn patterns from data using statistics and probability to make decisions, rather than relying on explicit rule-based programming.                                                                                                                                                                                           |
| [[002 Intoduction to ML#Supervised learning\|Supervised Learning (SL)]]                                         | ML paradigm where a model trains on labelled data pairs $(x, y)$ consisting of input features and target labels to predict outcomes for unseen data.                                                                                                                                                                                                                                     |
| [[002 Intoduction to ML#Unsupervised learning\|Unsupervised Learning (UL)]]                                     | ML paradigm where a model learns from unlabelled data to discover hidden patterns, underlying structures, groupings (clustering), or reduced representations without known answers.                                                                                                                                                                                                      |
| [[002 Intoduction to ML#Reinforcement learning\|Reinforcement Learning (RL)]]                                   | ML paradigm where an autonomous agent learns optimal decision-making strategies by interacting with an environment, receiving rewards for desirable actions and penalties for errors.                                                                                                                                                                                                    |
| [[002 Intoduction to ML#Supervised learning\|Features & Labels]]                                                | **Features ($x$)**: Input attributes or measurable variables describing data.<br>**Labels ($y$)**: Ground-truth target outputs or answers the model aims to predict.                                                                                                                                                                                                                     |
| [[002 Intoduction to ML#Training and testing\|Training Set & Testing Set]]                                      | **Training set** (~80%): Data used by the model to adjust internal parameters.<br>**Testing set** (~20%): Hidden, unseen data held back to evaluate model generalisation.                                                                                                                                                                                                                |
| [[002 Intoduction to ML#Supervised learning\|Generalisation]]                                                   | The ability of a trained machine learning model to make accurate predictions on new, previously unseen data points.                                                                                                                                                                                                                                                                      |
| [[002 Intoduction to ML#Overfitting\|Overfitting]]                                                              | High-variance error where a model memorises training noise and specific details, performing exceptionally well on training data but poorly on unseen test data.                                                                                                                                                                                                                          |
| [[002 Intoduction to ML#Underfitting\|Underfitting]]                                                            | High-bias error where a model is too simple to capture underlying data structures, resulting in poor performance on both training and testing datasets.                                                                                                                                                                                                                                  |
| [[002 Intoduction to ML#The model\|Model]]                                                                      | The mathematical framework or computational structure that transforms input features into predictions by learning parameter weights from data.                                                                                                                                                                                                                                           |
| [[002 Intoduction to ML#Unsupervised learning\|Clustering]]                                                     | An unsupervised learning task of partitioning unlabelled data points into distinct groups based on feature similarity.                                                                                                                                                                                                                                                                   |
| [[002 Intoduction to ML#Teaching a robot to walk\|Agent & Environment]]                                         | **Agent**: The active decision-maker in RL.<br>**Environment**: The external world or system with which the agent interacts.                                                                                                                                                                                                                                                             |
| [[002 Intoduction to ML#Teaching a robot to walk\|Rewards & Penalties]]                                         | Scalar feedback signals in RL; positive reward reinforces effective actions, penalty penalises undesirable outcomes to maximise cumulative long-term reward.                                                                                                                                                                                                                             |
| [[002 Intoduction to ML#Parameters\|Parameters]]                                                                | Internal numerical variables (such as weights $\mathbf{w}$ and bias $b$) learned and updated automatically by the model during training to map inputs to targets.                                                                                                                                                                                                                        |
| [[002 Intoduction to ML#Loss function\|Loss Function (Cost Function)]]                                          | A mathematical objective function $J(\mathbf{w}, b)$ quantifying prediction error by comparing model outputs against actual target values.                                                                                                                                                                                                                                               |
| [[003 Supervised learning#Problem types in SL\|Classification]]                                                 | Supervised learning task where the target output variable is discrete or categorical (e.g., binary classification, multi-class labels).                                                                                                                                                                                                                                                  |
| [[003 Supervised learning#Problem types in SL\|Regression]]                                                     | Supervised learning task where the target output variable is continuous and numerical (e.g., house price forecasting, temperature prediction).                                                                                                                                                                                                                                           |
| [[003 Supervised learning#==Algo1: Linear regression==\|Linear Regression (LR)]]                                | Supervised algorithm modeling a linear relationship between input features and a continuous target by fitting a straight line or hyperplane $\hat{y} = \mathbf{w}^T \mathbf{x} + b$.                                                                                                                                                                                                     |
| [[003 Supervised learning#==Algo1: Linear regression==\|Independent & Dependent Variables]]                     | **Independent variable ($x$)**: Input feature variable.<br>**Dependent variable ($y$)**: Target output variable whose value depends on $x$.                                                                                                                                                                                                                                              |
| [[003 Supervised learning#2 types of LR\|Simple vs Multiple Linear Regression]]                                 | **Simple LR**: Uses a single feature $x$ ($\hat{y} = w x + b$).<br>**Multiple LR**: Uses multiple features $x_1, \dots, x_n$ ($\hat{y} = \mathbf{w}^T \mathbf{x} + b$).                                                                                                                                                                                                                  |
| [[003 Supervised learning#Finding the best-fit line\|Residual]]                                                 | The difference between an actual target value $y_i$ and the predicted value $\hat{y}_i$: $\text{Residual} = y_i - \hat{y}_i$.                                                                                                                                                                                                                                                            |
| [[003 Supervised learning#Finding the best-fit line\|Least Squares Method]]                                     | Method used to find the best-fit line by minimising the Sum of Squared Errors: $\text{SSE} = \sum_{i=1}^n (y_i - \hat{y}_i)^2$.                                                                                                                                                                                                                                                          |
| [[003 Supervised learning#The cost function\|Mean Squared Error (MSE)]]                                         | Standard regression cost function calculating average squared difference: $J(w, b) = \frac{1}{2n} \sum_{i=1}^n (\hat{y}_i - y_i)^2$. Penalises larger errors heavily.                                                                                                                                                                                                                    |
| [[003 Supervised learning#Parameter optimisation with gradient descent\|Gradient Descent]]                      | Iterative optimisation algorithm updating parameters in the direction of steepest cost decrease: $w \leftarrow w - \alpha \frac{\partial J}{\partial w}$.                                                                                                                                                                                                                                |
| [[003 Supervised learning#Parameter optimisation with gradient descent\|Learning Rate]]                         | Hyperparameter controlling the step size taken during each iteration of gradient descent toward the minimum cost.                                                                                                                                                                                                                                                                        |
| [[003 Supervised learning#Fundamental assumptions of LR\|Assumptions of LR]]                                    | 1. **Linearity**: Linear relationship between features and target.<br>2. **Independence**: Residual errors are independent.<br>3. **Homoscedasticity**: Constant error variance.<br>4. **Normality**: Residuals follow normal distribution.<br>5. **No Multicollinearity**: Features are not highly correlated.<br>6. **Additivity**: Total effect is sum of individual feature effects. |
| [[003 Supervised learning#Fundamental assumptions of LR\|Homoscedasticity & Heteroscedasticity]]                | **Homoscedasticity**: Residual error variance remains constant across all feature levels.<br>**Heteroscedasticity**: Systematic change or spread in error variance across feature ranges.                                                                                                                                                                                                |
| [[003 Supervised learning#Fundamental assumptions of LR\|Multicollinearity]]                                    | High linear correlation between independent features in multiple regression, inflating parameter variance and degrading interpretability.                                                                                                                                                                                                                                                |
| [[003 Supervised learning#Evaluation metrics for regression\|Regression Metrics]]                               | **MAE**: $\frac{1}{n} \sum \|y_i - \hat{y}_i\|$ (outlier robust).<br>**RMSE**: $\sqrt{\text{MSE}}$ (in target units).<br>**$R^2$**: $1 - \frac{\text{SSE}}{\text{SST}}$ (proportion of explained variance).<br>**Adjusted $R^2$**: $R^2$ penalising irrelevant features.                                                                                                                 |
| [[003 Supervised learning#Regularisation techniques\|Regularisation]]                                           | Technique adding penalty terms to cost function to prevent overfitting.<br>• **L1 Lasso**: $\lambda \sum \|w_i\|$ (drives weights to zero, feature selection).<br>• **L2 Ridge**: $\lambda \sum w_i^2$ (shrinks weights evenly).<br>• **Elastic Net**: Combines L1 and L2 penalties.                                                                                                     |
| [[003 Supervised learning#==Algo2: Logistic regression==\|Logistic Regression (LogR)]]                          | Supervised classification algorithm mapping linear outputs to class probabilities using the sigmoid function.                                                                                                                                                                                                                                                                            |
| [[003 Supervised learning#The sigmoid function\|Sigmoid Function]]                                              | S-shaped activation function mapping any real number $z$ into the probability range $[0, 1]$: $\sigma(z) = \frac{1}{1 + e^{-z}}$.                                                                                                                                                                                                                                                        |
| [[003 Supervised learning#Odds and log-odds\|Odds & Log-Odds (Logit)]]                                          | **Odds**: Ratio of event probability to non-event probability $\frac{p}{1-p}$.<br>**Log-Odds (Logit)**: Natural log of odds $\ln(\frac{p}{1-p}) = \mathbf{w}^T \mathbf{x} + b$.                                                                                                                                                                                                          |
| [[003 Supervised learning#Cost function: Log-loss\|Log-Loss (Binary Cross-Entropy)]]                            | Convex loss function for classification: $J = -\frac{1}{n} \sum [y_i \ln \hat{y}_i + (1-y_i) \ln(1-\hat{y}_i)]$. Penalises confident wrong predictions exponentially.                                                                                                                                                                                                                    |
| [[003 Supervised learning#Cost function: Log-loss\|Maximum Likelihood Estimation (MLE)]]                        | Statistical method for estimating model parameters by maximising the likelihood function of observing given data labels.                                                                                                                                                                                                                                                                 |
| [[003 Supervised learning#Types of LogR\|Softmax Function]]                                                     | Multi-class extension of sigmoid mapping raw score vector to normalised probability distribution: $P(Y=c\mid\mathbf{x}) = \frac{e^{z_c}}{\sum e^{z_k}}$.                                                                                                                                                                                                                                 |
| [[003 Supervised learning#Types of LogR\|Binomial, Multinomial & Ordinal LogR]]                                 | **Binomial**: 2 binary classes.<br>**Multinomial**: $\ge 3$ unordered classes.<br>**Ordinal**: $\ge 3$ ordered classes.                                                                                                                                                                                                                                                                  |
| [[003 Supervised learning#Evaluation metrics\|Confusion Matrix]]                                                | A table summarising classification performance showing True Positives (`TP`), True Negatives (`TN`), False Positives (`FP`), and False Negatives (`FN`).                                                                                                                                                                                                                                 |
| [[003 Supervised learning#Evaluation metrics\|Classification Metrics]]                                          | **Accuracy**: $\frac{TP+TN}{\text{Total}}$.<br>**Precision**: $\frac{TP}{TP+FP}$.<br>**Recall (TPR)**: $\frac{TP}{TP+FN}$.<br>**F1 Score**: Harmonic mean $2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$.                                                                                                                                       |
| [[003 Supervised learning#Evaluation metrics\|AUC-ROC]]                                                         | **ROC**: Plot of True Positive Rate vs False Positive Rate across thresholds.<br>**AUC**: Area Under ROC curve measuring overall class separability ($0.5$ = random guessing, $1.0$ = perfect).                                                                                                                                                                                          |
| [[003 Supervised learning#==Algo3: Decision trees==\|Decision Tree (DT)]]                                       | Non-parametric algorithm organising decision logic into a tree structure of recursive conditional checks for classification and regression.                                                                                                                                                                                                                                              |
| [[003 Supervised learning#Structure of a DT\|Tree Structure (Root, Internal, Leaf Nodes)]]                      | **Root Node**: Top initial feature test.<br>**Internal Node**: Intermediate split check.<br>**Branch**: Condition outcome path.<br>**Leaf Node**: Terminal prediction value.                                                                                                                                                                                                             |
| [[003 Supervised learning#How a DT works\|Node Purity]]                                                         | Measure of homogeneity within a tree node; a pure node contains samples belonging exclusively to one class.                                                                                                                                                                                                                                                                              |
| [[003 Supervised learning#1. Information gain and Entropy\|Entropy & Information Gain]]                         | **Entropy**: Impurity measure $-\sum p_i \log_2(p_i)$ ($0$ = pure, $1$ = max impurity).<br>**Information Gain**: Entropy reduction achieved after splitting data on feature $A$.                                                                                                                                                                                                         |
| [[003 Supervised learning#2. Gini impurity\|Gini Impurity]]                                                     | Impurity measure $1 - \sum p_i^2$ calculating misclassification probability. Computationally faster than entropy because it avoids logarithms.                                                                                                                                                                                                                                           |
| [[003 Supervised learning#==Algo4: Random forest==\|Random Forest (RF)]]                                        | Ensemble method combining multiple decision trees trained with bagging and random feature selection, aggregating predictions by majority vote or averaging.                                                                                                                                                                                                                              |
| [[003 Supervised learning#==Algo4: Random forest==\|Ensemble Learning]]                                         | Paradigm combining predictions from multiple individual models (weak/strong learners) to construct a stronger, more accurate predictor.                                                                                                                                                                                                                                                  |
| [[003 Supervised learning#Working mechanism: Bagging and feature randomness\|Bootstrap Aggregating (Bagging)]]  | Training ensemble trees on distinct random bootstrap samples drawn with replacement from the original dataset to reduce variance.                                                                                                                                                                                                                                                        |
| [[003 Supervised learning#Working mechanism: Bagging and feature randomness\|Feature Randomness]]               | Selecting from a random subset of features at each split in Random Forest to decorrelate individual trees.                                                                                                                                                                                                                                                                               |
| [[003 Supervised learning#Out-of-bag (OOB) error\|Out-of-Bag (OOB) Error]]                                      | Validation metric evaluated on the ~36.8% left-out bootstrap samples for each tree, providing an unbiased error estimate without a test set.                                                                                                                                                                                                                                             |
| [[003 Supervised learning#==Algo5: Support vector machines==\|Support Vector Machine (SVM)]]                    | Algorithm finding the optimal hyperplane maximising the margin distance between support vectors of opposing classes.                                                                                                                                                                                                                                                                     |
| [[003 Supervised learning#^58c412\|Hyperplane]]                                                                 | A $d-1$ dimensional linear decision boundary subspace separating classes in a $d$-dimensional feature space.                                                                                                                                                                                                                                                                             |
| [[003 Supervised learning#Key concepts\|Support Vectors]]                                                       | Data points situated closest to the decision hyperplane that define its location, orientation, and margin boundary.                                                                                                                                                                                                                                                                      |
| [[003 Supervised learning#Key concepts\|Margin]]                                                                | The perpendicular distance between the decision hyperplane and the closest support vectors of any class.                                                                                                                                                                                                                                                                                 |
| [[003 Supervised learning#Hard margin versus soft margin\|Hard Margin vs Soft Margin SVM]]                      | **Hard Margin**: Enforces strict linear separation without misclassifications.<br>**Soft Margin**: Uses slack variables ($\xi_i$) and penalty $C$ to allow controlled margin violations for noisy data.                                                                                                                                                                                  |
| [[003 Supervised learning#Hard margin versus soft margin\|Slack Variables]]                                     | Penalty variables in soft-margin SVM measuring the distance by which data points violate the margin boundary.                                                                                                                                                                                                                                                                            |
| [[003 Supervised learning#The Hinge loss function\|Hinge Loss]]                                                 | Loss function $\max(0, 1 - y_i(\mathbf{w}^T \mathbf{x}_i + b))$ penalising predictions lying inside the margin or misclassified.                                                                                                                                                                                                                                                         |
| [[003 Supervised learning#Non-linear SVM and the kernel trick\|Kernel Trick & Functions]]                       | Technique mapping non-linearly separable data into higher dimensions using kernel functions (Linear, Polynomial, RBF) to enable linear separation.                                                                                                                                                                                                                                       |
| [[003 Supervised learning#==Algo6: K-nearest neighbors==\|K-Nearest Neighbors (KNN)]]                           | Non-parametric, instance-based lazy learning algorithm classifying query points by majority vote of $k$ closest neighbors.                                                                                                                                                                                                                                                               |
| [[003 Supervised learning#==Algo6: K-nearest neighbors==\|Instance-Based Learner (Lazy Learner)]]               | Model that skips explicit training, storing raw data instances and deferring prediction computations until query time.                                                                                                                                                                                                                                                                   |
| [[003 Supervised learning#Distance metrics\|Distance Metrics]]                                                  | Formulas measuring feature space proximity:<br>• **Euclidean**: $\sqrt{\sum (x_i - y_i)^2}$<br>• **Manhattan**: $\sum \|x_i - y_i\|$<br>• **Minkowski**: $(\sum \|x_i - y_i\|^p)^{1/p}$                                                                                                                                                                                                  |
| [[003 Supervised learning#Limitations\|Curse of Dimensionality]]                                                | Phenomenon where high-dimensional feature spaces become sparse, causing distance metrics to lose discriminative power.                                                                                                                                                                                                                                                                   |
| [[003 Supervised learning#==Algo7: Gradient boosting==\|Gradient Boosting]]                                     | Ensemble technique building weak decision trees sequentially, where each new tree fits the residual loss gradients of previous trees.                                                                                                                                                                                                                                                    |
| [[003 Supervised learning#==Algo7: Gradient boosting==\|Weak Learner]]                                          | Simple base model performing slightly better than random guessing (e.g. shallow decision tree or decision stump).                                                                                                                                                                                                                                                                        |
| [[003 Supervised learning#Learning rate and shrinkage\|Shrinkage (Learning Rate)]]                              | Scaling factor $\eta \in (0, 1]$ dampening individual weak tree contributions in gradient boosting to control learning rate and avoid overfitting.                                                                                                                                                                                                                                       |
| [[003 Supervised learning#AdaBoost vs Gradient boosting\|AdaBoost vs Gradient Boosting]]                        | **AdaBoost**: Re-weights misclassified instances using exponential loss on decision stumps.<br>**Gradient Boosting**: Fits sequential weak trees to continuous residual gradients of any differentiable loss function.                                                                                                                                                                   |
| [[003 Supervised learning#==Algo8: Naive Bayes==\|Naive Bayes]]                                                 | Probabilistic classifier based on Bayes' Theorem assuming conditional independence between features given the class label.                                                                                                                                                                                                                                                               |
| [[003 Supervised learning#Bayes' theorem and the naive independence assumption\|Bayes' Theorem]]                | Formula calculating posterior probability: $P(y \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid y) P(y)}{P(\mathbf{x})}$.                                                                                                                                                                                                                                                                     |
| [[003 Supervised learning#Bayes' theorem and the naive independence assumption\|Bayesian Terms]]                | **Prior ($P(y)$)**: Initial class probability.<br>**Likelihood ($P(\mathbf{x}\mid y)$)**: Feature probability given class.<br>**Posterior ($P(y\mid \mathbf{x})$)**: Updated class probability.<br>**Marginal ($P(\mathbf{x})$)**: Total evidence probability.                                                                                                                           |
| [[003 Supervised learning#Bayes' theorem and the naive independence assumption\|Naive Independence Assumption]] | Assumption that features are conditionally independent given class label $y$: $P(x_1, \dots, x_n \mid y) = \prod P(x_i \mid y)$.                                                                                                                                                                                                                                                         |
| [[003 Supervised learning#Types of Naive Bayes models\|Naive Bayes Variants]]                                   | **Gaussian**: Continuous features following normal distribution.<br>**Multinomial**: Discrete word/term counts.<br>**Bernoulli**: Binary presence/absence features.                                                                                                                                                                                                                      |
| [[003 Supervised learning#Limitations\|Zero-Frequency Problem & Laplace Smoothing]]                             | **Zero-Frequency**: Unseen categorical value resulting in zero joint probability.<br>**Laplace Smoothing**: Adding pseudo-counts ($+1$) to avoid zero probabilities.                                                                                                                                                                                                                     |
| Bias-Variance Tradeoff                                                                                          | Fundamental ML trade-off. **Bias** is error from oversimplified model assumptions (underfitting). **Variance** is sensitivity to training set noise (overfitting). Total Error = $\text{Bias}^2 + \text{Variance} + \text{Irreducible Error}$.                                                                                                                                           |
| Hyperparameter vs Parameter                                                                                     | **Hyperparameters**: External settings configured before training (e.g. learning rate $\alpha$, tree max-depth, $k$ in KNN, $C$ in SVM).<br>**Parameters**: Internal values learned automatically during training (e.g. weights $w$, bias $b$).                                                                                                                                          |
| Cross-Validation ($k$-Fold CV)                                                                                  | Resampling technique dividing dataset into $k$ equal folds, iteratively training on $k-1$ folds and testing on 1 fold to evaluate true generalisation performance.                                                                                                                                                                                                                       |
| Feature Scaling (Standardisation & Normalisation)                                                               | Rescaling input features to comparable numerical ranges.<br>• **Standardisation (Z-score)**: $\frac{x - \mu}{\sigma}$ (mean 0, std 1).<br>• **Normalisation (Min-Max)**: $\frac{x - x_{\min}}{x_{\max} - x_{\min}}$ ($[0, 1]$ range). Essential for distance and gradient algorithms.                                                                                                    |
| Decision Boundary                                                                                               | Hyper-surface or line in feature space separating regions assigned to different target classes by a classification algorithm.                                                                                                                                                                                                                                                            |
| Decision Stump                                                                                                  | A 1-level decision tree consisting of a single internal split directly connected to leaf nodes, commonly used as a weak learner in boosting algorithms like AdaBoost.                                                                                                                                                                                                                    |
| Parametric vs Non-parametric Models                                                                             | **Parametric**: Fixed number of parameters independent of data size (e.g., Linear/Logistic Regression).<br>**Non-parametric**: Flexible structure where model capacity grows with data size (e.g., Decision Trees, KNN, SVM with RBF kernel).                                                                                                                                            |
| Convex vs Non-Convex Optimisation                                                                               | **Convex**: Cost function with a single global minimum and no local minima traps (e.g., MSE in Linear Regression, Log-Loss in Logistic Regression).<br>**Non-Convex**: Cost function with multiple local minima and saddle points (e.g., MSE in Logistic Regression, Neural Networks).                                                                                                   |
| One-Hot Encoding                                                                                                | Categorical feature engineering method converting $N$ discrete categories into $N$ binary columns ($0$ or $1$) to avoid false ordinal assumptions.                                                                                                                                                                                                                                       |
